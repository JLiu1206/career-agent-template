# profile

Who you are, as facts with sources. `/career-setup` creates these files, and
nothing is written until you approve it:

- `profile.md`: your CV transcribed. Every fact carries `[src: <file>]`.
- `story-bank.md`: your best stories, each with the competencies it shows
  and a wear count.
- `strengths-gaps.md`: a frank read of where you are strong and thin. It's
  written by Claude, so check it.
- `resolutions.md`: decisions you've made, such as which version of a result
  to use, or a fact you confirmed in conversation. It overrides every other
  source.
- `current-cv.md`: which CV file the profile came from, with its hash, so a
  changed CV is noticed.

You own these files. Edit them directly whenever something is wrong. Agents
only propose changes.
