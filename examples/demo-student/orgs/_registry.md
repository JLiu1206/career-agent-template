# Organisation registry

One row per organisation you apply to. `/apply` adds rows for you, so you
rarely need to edit this by hand. The slug is how every other file refers to
the organisation, so never rename one.

- **kind**: `employer`, `research-group` or `other`
- **sector**: free text, for example `engineering`, `consulting`, `finance`, `academia`
- **aliases**: other names the organisation goes by, comma-separated
